# АЙ-САНАА — адаптивный веб-прототип

Готовая одностраничная страница по README_FOR_CODEX.md. Русский язык, девять смысловых разделов, фотографии сообщества, локальные кириллические шрифты Cormorant Garamond и Manrope, бумажная графика SVG/CSS и декоративный сгенерированный натюрморт. Скриншоты референсов не используются на странице. Цветок в оформлении — декоративный элемент прототипа, а не утверждённый логотип.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://localhost:5173).

```sh
npm run build
npm run preview
```

Результат сборки — `dist/`.

В папке `preview/` находится автономный файл [`АЙ-САНАА.html`](preview/АЙ-САНАА.html): его можно открыть двойным щелчком, без Node.js и подключения к интернету. Изображения, шрифты, стили и скрипт встроены в него.

## Поведение

- Ссылки навигации ведут к разделам.
- Мобильное меню открывается и закрывается; закрывается при выборе пункта и по Escape.
- Кнопки тарифов открывают нативное модальное окно с названием выбранного тарифа и сообщением «Оплата будет подключена позже». Закрытие — кнопкой, Escape или кликом на фон. Нативный dialog удерживает фокус, браузер возвращает его к кнопке после закрытия.
- FAQ на нативных `details`/`summary`, поддерживает клавиатуру.
- Учтён `prefers-reduced-motion`, есть подписи изображений и переход к основному содержанию.
- Никакие данные не собираются и не отправляются. Оплаты, аналитики, бэкенда и интеграций нет.

## Проверено

- Производственная сборка Vite и синтаксис JavaScript.
- Наличие локальных файлов и ссылок, поддержка кириллицы шрифтами.
- Контент и тарифы сверены с README_FOR_CODEX.md.
- Адаптивные правила рассчитаны для мобильных экранов, планшетов и десктопов. Исправлены потенциально тесные заголовки на 320 и 768 px; зелёный затемнён для контраста светлого текста (около 4.85:1).
- Визуальная проверка в браузере на 390 и 1440 px НЕ выполнена: инструмент управления браузером `cua_repl.js` отсутствует в данной сессии. Скриншотов нет. Это остаётся обязательной проверкой перед публикацией.

Имя, биография и портрет Нюргуяны Петровой обновлены по присланным материалам пользователя.

## Требует подтверждения перед запуском
- Утверждённый логотип и разрешение использовать предоставленные фотографии.
- Время, адрес и формат каждой встречи.
- Официальные соцсети и контакты.
- Условия специальных мероприятий, окончательные юридические документы и реквизиты для будущего подключения оплаты.

Старт продаж в тексте: 16 ноября 2026. Страница не опубликована.

## Обновлённый дизайн

Более спокойная редакционная композиция по мотивам творческих мастерских: бумажная фактура, антиква с курсивом, тёплые приглушённые оттенки, клетчатые заметки. Фотографии расположены в потоке без наложения друг на друга; на телефоне блоки следуют последовательно. Натюрморт `creative-desk.png` сгенерирован для оформления; фотографии людей остаются исходными. GitHub Pages использует папку `docs` в ветке `main`.

- Эти условия обновлены по последнему сообщению пользователя и имеют приоритет перед исходным README_FOR_CODEX.md.
- Убраны точки в заголовках и иконки-стрелки. Во всех местах с цветком используется фирменный знак. Перечень аудитории оформлен без цветных плашек.

## Яркое оформление и анимация

Визуальный слой `src/vivid.css`: насыщенный розовый, солнечный жёлтый, сиреневый; округлые формы, вырезанные сгенерированные предметы керамики и творчества на прозрачном фоне. Все видимые тексты сохранены относительно версии ad98143.

Анимация: мягкое покачивание кружки и палитры, движение ленты, появление разделов при прокрутке через IntersectionObserver. Учтён prefers-reduced-motion; без JavaScript контент остаётся видимым. Сборка, пути к изображениям, прозрачность PNG, неизменность текста и размеры заголовка проверены. Визуальная браузерная проверка не выполнена — инструмент управления браузером недоступен.

## Обложка и календарь

Обложка с текстом по центру и вырезанными предметами по краям; яркие органические подложки. На мобильном предметы располагаются у верхних краёв, чтобы не перекрывать текст. Две SVG-ленты с вдохновляющими словами соединяют разделы. Ближайшие встречи оформлены как отрывные страницы календаря с датами 20 ноября, 29 ноября и 4 декабря; исходные описания и остальные тексты сохранены.
